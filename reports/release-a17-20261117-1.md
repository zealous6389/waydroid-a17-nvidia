# Android 17 NVIDIA 620.70.06 — a17-20261117-1

The prebuilt package in this release is the exact `20261117.1-1` package
installed and tested on the fork owner's RTX 4060 Ti (8 GiB), NVIDIA
open 620.70.06, CachyOS and KDE Plasma Wayland.

## Changes

- Add an exact 620.70.06 RM ABI profile, attributed to
  [Shiro836/nvidia-prolapse#1](https://github.com/Shiro836/nvidia-prolapse/pull/1).
  Preserve unknown-version rejection and the canonical 615 ABI.
- Rebuild Waydroid's Rust RM, Mesa NVK and nvrm userspace libraries for
  Android x86_64 and x86. The installed host NVIDIA driver is not replaced.
- Ship a matching ext4 vendor-image repack, retaining the published
  Android 17 Codec2 service and other vendor modules. **Not a full Soong
  vendorimage rebuild.** All 19 mapped binaries match the native bundle.
- Restore the original build/test/release workflows in English, with
  fork-target safeguards, regression tests and reversible image repacking.
- Distribute through this GitHub fork, with nine checksum-pinned PKGBUILD
  inputs; no AUR publication or account is needed.

## Validation

- Installed release gate: **22 cases + media passed** on loaded 620.70.06,
  covering both Android ABIs.
- Android SurfaceFlinger: ANGLE → Vulkan → NVK on **RTX 4060 Ti**.
  Operator confirmed the desktop visibly renders.
- ByteBuffer decode: AVC, HEVC, VP9, AV1, **60 frames each, zero bad buffers**.
- Encode: AVC, HEVC, AV1, **60 in / 60 out**; FFmpeg clean, ffprobe confirms
  60 frames for each.
- PRIVATE Surface decode: all four codecs, **60 inputs / outputs / images**,
  EOS, zero errors and clean destruction.
- Running flush, destruction with queued work and malformed-input rejection
  passed. No matching NVIDIA Xid/fault/timeout kernel messages were found.
- Host: 272 CPU tests, 13 supported Ada fixtures, 9 decode cases, 15 encode
  cases and the Mesa graphics/compute multiqueue lifecycle probe passed.
- Public-header oracle: **1,001 checks per ABI**, m32 and m64 passed.

**Not tested:** Chrome WebCodecs/WebRTC (Chrome is absent), seccomp syscall
tracing, guest VP9 superframe cases, KernelSU and broader desktop integration
regressions. No new performance or long-term stability claim.
Strict Clippy still fails with the same 60 preexisting baseline diagnostics.
See [the detailed report](nvidia-620.md).

## Install

Review the PKGBUILD before running it. On Arch/CachyOS with `base-devel`
and `git`:

```bash
git clone --branch a17-20261117-1 https://github.com/zealous6389/waydroid-a17-nvidia.git
cd waydroid-a17-nvidia/aur/waydroid-a17-nvidia-bin
makepkg --verifysource
makepkg -si
```

Alternatively, verify `SHA256SUMS` and install the included prebuilt
`waydroid-a17-nvidia-bin-20261117.1-1-x86_64.pkg.tar.zst` with `sudo pacman -U`.
It is unsigned at the pacman-package layer; the repository commit/tag are
SSH-signed. Checksums provide integrity, not independent publisher trust.

Follow the repository README for the separate WayDroid-ATV Android 17
system image and `sudo waydroid-nvidia-setup`. This run used the VANILLA
`20261017` system image; Android data and that system image are not included
in the release. Setup gates the vendor image on the loaded NVIDIA module.
An unrecognized driver update is rejected rather than bypassed.
